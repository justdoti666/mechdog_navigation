## 背景

环境自适应权重的输入链路：
```
TSL2591 红外通道原始值 (0~65535)
  → 归一化: raw / IR_MAX_REF          (当前 20000)
  → 阈值判定: ≤0.10 INDOOR / ≥0.40 OUTDOOR / 之间 SEMI_INDOOR
  → 权重: indoor(astra 0.8) / semi(0.5) / outdoor(0.1)
```
当前 `IR_MAX_REF=20000` 与阈值 `0.10/0.40` 是**按传感器手册量程推算的预设值**，未实测。

## §1 TSL2591 三场景标定流程

### 步骤 1：采集原始值

增益配置：25x（`TSL2591_CTRL_25X_100MS`，100ms 积分）。每个场景连续读 20 次取均值与范围：

| 场景 | 环境描述 | 期望原始值 | 实测均值 | 实测范围 |
|---|---|---|---|---|
| A 室内 | 无阳光直射，普通照明 | ~200-2000 | | |
| B 半室外（窗边） | 窗边/棚下/阴天室外 | ~2000-8000 | | |
| C 室外（太阳直射） | 阳光直射传感器 | >20000 | | |

### 步骤 2：计算归一化值

`norm = raw / IR_MAX_REF`。用实测范围核对三档是否落在预期区间：
- A 应 ≤ 0.10 → INDOOR
- B 应 0.10~0.40 → SEMI_INDOOR
- C 应 ≥ 0.40（>20000 时 clamp 1.0）→ OUTDOOR

若某档落在错误区间：优先调 `IR_MAX_REF`（分母），使 C 场景归一化值 ≥0.5 左右；
其次微调 `ir_indoor_max / ir_outdoor_min`，保证三档之间有 ≥0.05 的判定余量。

### 步骤 3：回填

修改 `config.h::IrConfig` 与 `sensor_ir.h::IR_MAX_REF`，注释中记录本次实测数据与日期。

### 步骤 4：验证

1. `ctest` 全绿（模拟三档覆盖断言不受影响）
2. 真机在 A/B/C 三场景各运行 30 秒，`fusion_result` 的 `environment` 字段应分别稳定为对应档位
3. 边界场景（黄昏/阴天室内靠窗）记录实际判定，确认无抖动（连续 5 秒内档位不跳变）
